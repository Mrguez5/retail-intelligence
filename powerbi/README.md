# Power BI version

The same four views as the HTML dashboard (overview, price vs competitor, supplier invoices,
data quality) as a Power BI project, with slicers that filter every visual on the page.

The project is stored as **PBIP** (text: TMDL semantic model + PBIR report), generated by
`pipeline/powerbi.py`, so every change is reviewable in git.

## Open it

1. Build the data and the project (Power BI Desktop closed):
   ```
   python run.py all        # pipeline: bronze -> silver -> gold
   python run.py powerbi    # gold -> data/powerbi/*.parquet + powerbi/RetailIntelligence.pbip
   ```
2. Open `powerbi/RetailIntelligence.pbip` in Power BI Desktop.
3. **Home > Refresh** (first time only, and after re-running the pipeline).

The model reads the Parquet files from the `DataFolder` parameter. In the repository it holds a
placeholder (`C:\path\to\retail-intelligence\data\powerbi`); `python run.py powerbi` sets it to
this machine's path, so always run it before opening the project, and again after moving the
repository (or change it in **Transform data > Edit parameters**).

## Semantic model

| Table | Grain | Source |
|---|---|---|
| `FactSales` | one row per valid sales line | `gold.fct_sales` |
| `DimProduct`, `DimDate`, `DimChannel` | one row per product / day / channel | `gold.dim_*` |
| `PricePosition` | one row per product and week | `gold.mart_price_position_weekly` |
| `InvoiceAudit` | one row per supplier invoice PDF | `gold.mart_invoice_audit` |
| `Quarantine` | one row per channel and reason | `silver.silver_sales_quarantine` (counted) |
| `DataQuality` | one row per check | `gold.mart_data_quality` |

Relationships (single direction, dimension → fact): `DimDate` filters sales, price position and
invoices; `DimProduct` filters sales and price position; `DimChannel` filters sales and quarantine.

Main measures (display folders *Sales*, *Price*, *Invoices*, *Data Quality*): Net Revenue, Gross Margin %,
Units Sold, Orders (returns excluded), Avg Order Value, Price Gap (weighted by units), Gap Last
4 Weeks, Units per Product-Week, Titles Much Dearer, Duplicates To Block, Overcharges, Raw / Clean /
Quarantined Lines.

## Design

Dark "wallboard" theme (`StaticResources/RegisteredResources/RetailDark.json`). The overview is a
single-screen command center in three columns (sales · price vs competitor · supplier invoices):
large coloured tiles with month-on-month trends (▲/▼, green/red) and tables whose cells are
coloured by measures (margin %, price gap, invoice status). Colour helpers live in the hidden
*Formatting* display folder.

Publishing to the web needs a Power BI Pro licence; with a free account share the `.pbip`
folder (or save as `.pbix`) and the screenshots.
